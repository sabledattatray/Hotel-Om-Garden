## 📌 प्रकल्प परिचय (Project Overview)

**हॉटेल ओम गार्डन** हे अहमदनगर–सोलापूर महामार्गावरील मांदळी (ता. कर्जत) येथील एक प्रतिष्ठित फॅमिली रेस्टॉरंट आणि स्वतंत्र परवानाधारक परमिट रूम आहे. हे संकेतस्थळ अस्सल मराठी संस्कृती, पारंपारिक महाराष्ट्रीयन आदरातिथ्य, आणि आधुनिक डिजिटल तंत्रज्ञानाचा सुरेख संगम आहे.

संकेतस्थळामध्ये छत्रपती शिवाजी महाराजांचा राजेशाही वॉटरमार्क, स्वतंत्र फडफडणारा भगवा ध्वज (Bhagwa Flag), `#FF9933` (भगवा) व `#163B32` (डार्क फॉरेस्ट ग्रीन) ही वैशिष्ट्यपूर्ण रंगसंगती, शोधण्यायोग्य डिजिटल मेनू आणि पूर्णपणे सुरक्षित स्थानिक ॲडमिन सीएमएस (CMS) समाविष्ट आहे.

## 🌟 प्रमुख वैशिष्ट्ये (Key Highlights)

### 🚩 १. अस्सल मराठी व सांस्कृतिक डिझाइन
- **मराठी-प्रथम (Marathi-First)**: Google Fonts वरील `Noto Sans Devanagari` आणि `Noto Serif Devanagari` सह समृद्ध देवनागरी टायपोग्राफी.
- **भगवा रंगसंगती (`#FF9933`)**: प्राथमिक भगवा रंग, सोनेरी छटा आणि समृद्ध डार्क फॉरेस्ट ग्रीन पार्श्वभूमी.
- **छत्रपती शिवाजी महाराज वॉटरमार्क**: सिंहासनाधिष्ठित व अश्वारूढ राजमुद्रा-प्रेरित कलाकृतीचे पार्श्वभूमीवर अत्यंत आदरयुक्त व सूक्ष्म सादरीकरण.
- **लहराणारा भगवा ध्वज**: उच्च दर्जाचे व्हेक्टर ॲनिमेशन सह हवेत फडफडणारा भगवा झेंडा.

### 🍽️ २. शोधण्यायोग्य डिजिटल खाद्य मेनू (Searchable Menu)
- मराठी व इंग्रजी दोन्हीमध्ये तत्काळ शोध (Live Search - उदा. भाकरी, चिकन, पिठलं, मटण).
- शाकाहारी (`Veg`), मांसाहारी (`Non-Veg`) आणि अंड्याचे पदार्थ सुलभ फिल्टर.
- ज्या पदार्थांचे दर निश्चित नसतील तेथे *‘किंमत जाणून घेण्यासाठी संपर्क साधा’* असा पारदर्शक संदेश.
- ग्राहकांसाठी थेट मेनू प्रिंट (Print Menu) करण्याची सुविधा.

### 🍷 ३. कायदेशीर व स्वतंत्र परमिट रूम विभाग (Permit Room)
- फॅमिली रेस्टॉरंटच्या मुख्य भागापासून स्वतंत्र व मर्यादित माहिती.
- महाराष्ट्र राज्य उत्पादन शुल्क नियमांनुसार वयाची खात्री (Age Gate - २१/२५ वर्षे) आणि वैधानिक आरोग्य चेतावणी.
- कोणतीही मद्य जाहिरात किंवा ऑनलाइन विक्री नाही.

### 📝 ४. ऑनलाइन टेबल चौकशी (Table Enquiry Form)
- ग्राहकांसाठी सोपा व जलद टेबल आरक्षण फॉर्म (नाव, मोबाईल, व्यक्ती संख्या, वेळ).
- थेट WhatsApp व Click-to-Call द्वारे संपर्क.
- बॉट-ट्रॅप (Honeypot) स्पॅम संरक्षण.

### 🔐 ५. शक्तिशाली ॲडमिन सीएमएस (Owner Admin CMS)
- मार्ग: `/admin` | पासवर्ड: `omgarden123`
- **मेनू व्यवस्थापन**: नवीन पदार्थ जोडणे, दर बदलणे, उपलब्धता ऑन/ऑफ करणे.
- **चौकशी इनबॉक्स**: आलेल्या ग्राहकांच्या चौकशी पाहणे व एका क्लिकवर फोन करणे.
- **सुविधा व गॅलरी व्यवस्थापन**: फोटोग्राफ्स आणि रेस्टॉरंट सुविधा टॉगल करणे.
- **बॅकअप व रिस्टोअर**: सर्व डेटा सुरक्षित JSON फॉरमॅटमध्ये डाऊनलोड/अपलोड करण्याची सोय.
- **लाँच चेकलिस्ट**: व्यावसायिक पडताळणी सूची.

### 📱 ६. मोबाइल-प्रथम प्रतिसादात्मकता (Mobile-First UX)
- स्मार्टफोनवर स्क्रीनच्या १५% पेक्षा लहान स्टिकी बॉटम बार (Quick Call, WhatsApp, Directions).
- अतिजलद लोडिंग गती (Vite + Tailwind CSS).

## 🏗️ तांत्रिक रचना (Tech Stack)

| स्तर (Layer) | तंत्रज्ञान (Technology) | वर्णन (Purpose) |
|---|---|---|
| **Frontend Framework** | React 19 + TypeScript | जलद आणि सुरक्षित कंपोनंट-आधारित आर्किटेक्चर |

| **Icons** | Lucide React | हलके आणि सुस्पष्ट SVG आयकॉन्स |

| **Data & State** | React Context API + LocalStorage | विना-डेटाबेस झिरो-कॉस्ट संपूर्ण डेटा पर्सिस्टन्स |
| **SEO & Social** | Schema.org JSON-LD + OpenGraph | गुगल सर्च आणि व्हॉट्सॲप शेअरिंगसाठी परिपूर्ण मेटाडेटा |

## ⚡ जलद सुरुवात (Quick Start)

### पूर्वतयारी (Prerequisites)
- [Node.js](https://nodejs.org/) (आवृत्ती 18 किंवा नवीन)
- [npm](https://www.npmjs.com/) (किंवा bun / pnpm / yarn)
- [Git](https://git-scm.com/)

### १. प्रकल्प क्लोन करा (Clone Repository)
```bash
git clone https://github.com/<तुमचे-युझरनेम>/hotel-om-garden-website.git
cd hotel-om-garden-website
```

### २. डिपेंडन्सीज इन्स्टॉल करा (Install Dependencies)
```bash
npm install
```

### ३. डेव्हलपमेंट सर्व्हर सुरू करा (Start Development Server)
```bash
npm run dev
```
ब्राउझरमध्ये `http://localhost:3000` उघडा.

### ४. उत्पादन बिल्ड तयार करा (Build for Production)
```bash
npm run build
```
उत्पादन-तयार बिल्ड फाइल्स `dist/` फोल्डरमध्ये तयार होतील.

### ५. कोड तपासणी (Lint & Type Check)
```bash
npm run lint
```

## 📤 Git रिपॉझिटरीमध्ये पुश कसे करावे (Push to GitHub)

आपल्या स्वतःच्या GitHub खात्यावर हा कोड पुश करण्यासाठी खालील पायऱ्या करा:

```bash
# १. GitHub वर नवीन रिपॉझिटरी तयार करा (उदा. hotel-om-garden-website)

# २. रिमोट URL जोडा
git remote add origin https://github.com/<तुमचे-युझरनेम>/hotel-om-garden-website.git

# ३. मुख्य शाखा main म्हणून सेट करा
git branch -M main

# ४. कोड GitHub वर पुश करा
git push -u origin main
```

## 🔐 प्रशासक पॅनेल (Admin CMS)

हॉटेल व्यवस्थापकांसाठी मेनू आणि चौकशी नियंत्रित करण्यासाठी एक सुटसुटीत CMS उपलब्ध आहे:

| माहिती प्रकार | तपशील |
|---|---|
| **प्रवेश मार्ग (Route)** | `/admin` |
| **डीफॉल्ट पासवर्ड** | `omgarden123` |
| **डेटा साठवणूक** | ब्राउझर LocalStorage (कोणत्याही बाह्य सर्व्हर शुल्काशिवाय) |
| **बॅकअप पर्याय** | एका क्लिकवर संपूर्ण डेटा JSON फाइल स्वरूपात डाऊनलोड करता येतो |

> 💡 **टीप**: पासवर्ड बदलण्यासाठी `src/context/StoreContext.tsx` मधील `DEFAULT_ADMIN_PIN` अपडेट करा.

## 🚀 थेट होस्टिंग व डिप्लॉयमेंट (Deployment Options)

हे संकेतस्थळ पूर्णपणे क्लायंट-साइड स्टॅटिक SPA असल्याने खालील प्लॅटफॉर्म्सवर मोफत होस्ट करता येते:

### Vercel द्वारे:
```bash

```

### Netlify द्वारे:
1. Netlify वर नवीन साईट जोडा.
2. Build Command: `npm run build`
3. Publish Directory: `dist`

### GitHub Pages द्वारे:
Vite कॉन्फिगरेशनमध्ये `base: './'` ठेवून GitHub Actions द्वारे `dist` डिप्लॉय करा.
